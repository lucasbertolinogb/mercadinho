# mercadinho
Projeto sobre organização de um mercadinho na web


Mercadinho Online:<br>
Vai ser um mercado online na web com o uso da linguagem JavaScript com o React.js e <br> Prisma na compra e venda de produtos e o uso de empregados <br> 
na alteração dos produtos na loja 

Metas:<br>
*adcionar uso de cartão de crédito,  <br>
*Barra de Pesquisa <br>
*Carrinho de compras <br>
*Layout centralizado e fácil de usar no celular <br>
*Poderá adcionar de maneira fácil novos produtos <br>
 
Se possível: <br>
*Segurança na compra <br>
*Conta para logar ,exemplo: Gmail<br>
